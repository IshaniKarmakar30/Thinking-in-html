What is Generative AI?

  • AI that creates new content: text, images, code, audio, video
  • Learns patterns from huge datasets instead of following hand-written rules
  • Differs from traditional AI, which mostly classifies or predicts
  • Prompts in, original-looking output out

How Does It Work?

1. TrainModel learns statistical patterns from massive text, image or code corpora.
2. TokenizeInput is split into small pieces (tokens) and turned into numbers.
3. PredictA transformer predicts the most likely next token, again and again.
4. GenerateTokens are decoded back into readable text, pixels or audio.

Types of Generative Models

  • LLMs (transformers): chat, writing, summarizing, coding help
  • Diffusion models: image generation by gradually denoising
  • GANs: two networks compete to produce realistic samples
  • Multimodal models: combine text, images, audio in one system

Where GenAI Meets the Web

  • Web apps call AI models through REST APIs using fetch()
  • Responses can be streamed to show text as it is generated
  • AI assists developers: code completion, debugging, UI drafts
  • Keep API keys on a server, never in browser code
const res = await fetch("/api/chat", {
  method: "POST",
  body: JSON.stringify({ prompt })
});
const data = await res.json();

Responsible Use

  • Hallucinations: outputs can be fluent but wrong, so verify facts
  • Bias & privacy: models mirror their data; don't paste sensitive info
  • Copyright & integrity: cite AI help and follow college policy
  • Treat AI as an assistant, not a replacement for understanding
